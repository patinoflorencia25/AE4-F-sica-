## Estructura

## Reglas del proyecto
1. No se inventan datos, resultados, fuentes, fechas ni simulaciones.
2. Los datos "orientativos" del Banco no son datos definitivos hasta confirmar el caso.
3. Las versiones anteriores no se borran; cada versión nueva se guarda con su número.
4. El uso de IA se registra en `P4_registro-decisiones/` y en la declaración de la carátula (Anexo V).
